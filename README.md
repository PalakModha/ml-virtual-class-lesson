# ML Virtual Class Lesson

## Introduction to Machine Learning: Linear Regression

This repository contains the technical resources developed to support a virtual classroom lesson created as part of the **NSDC Yuva Teaching Assistant Internship**.

The lesson introduces beginners to the basic concepts of Machine Learning through a simple and relatable example: predicting examination marks from study hours.

---

## Practical Objective

The practical demonstrates how a Machine Learning model can learn a relationship between an input feature and a target variable and then use the learned relationship to make a prediction.

### Feature

**Study Hours**

### Target

**Exam Marks**

---

## Dataset

The educational dataset contains the following observations:

| Study Hours | Exam Marks |
|-------------|------------|
| 1 | 35 |
| 2 | 42 |
| 3 | 50 |
| 4 | 55 |
| 5 | 65 |
| 6 | 70 |
| 7 | 78 |
| 8 | 85 |

---

## Machine Learning Method

The project uses **Linear Regression**, a supervised Machine Learning technique used to model relationships between variables and predict continuous numerical outcomes.

The basic workflow is:

**Data → Training → Model → New Input → Prediction**
